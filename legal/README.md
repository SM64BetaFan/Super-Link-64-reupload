# Legal documentation

This directory records the intended licensing and distribution boundary for
Super Link 64. It does not resolve third-party rights and does not authorize a
release.

- `LICENSING_POLICY.md` defines what the project's AGPL declaration covers.
- `ROM_ASSET_POLICY.md` defines the repository and package exclusions.
- `DISTRIBUTION_POLICY.md` separates this original source-only scaffold from the
  evidence required before any combined or object-code distribution.

The root `NOTICE.md`, `THIRD_PARTY.yml`, and `RELEASE_BLOCKERS.md` are part of
the same control set. If these documents disagree, the more restrictive rule
applies until the discrepancy is reviewed and corrected.

Do not mark a blocker complete based on an assumption, an informal description
of a project as open source, or the mere availability of source code. Record
the exact license text, rights holder or authorized representative, covered
revision, date, and durable evidence for every clearance decision.
